# 情報分析ツール システマ

![GitHub](https://img.shields.io/badge/Version-1.0.0-blue) ![Build](https://img.shields.io/badge/Build-Passing-green)

このツールは、ヤフオクの**購入**や**出品**に関する商品の価格や傾向を分析し、ユーザーに最適な意思決定をサポートします。相場データや現在出品中の商品を活用し、市場動向を可視化します。

## 主な機能

### 1. 相場検索
- **概要**: 商品名で検索し、過去180日間の落札データを取得。
- **特徴**:
  - 落札金額や落札数を確認。
  - **入札数**や**価格**でフィルタリング可能。
- **用途**: 過去の相場を基に購入や出品の戦略を立てる。

### 2. 現在価格検索
- **概要**: 商品名で検索し、現在出品中の商品データを取得。
- **特徴**:
  - 現在の金額や入札数を確認。
  - **入札数**や**価格**でフィルタリング可能。
- **用途**: リアルタイムの市場価格を把握。

### 3. 相場再検索（実装予定）
- **概要**: 相場検索で取得したデータを再度確認。
- **予定機能**:
  - データの更新や削除で整理。
- **目標**: ユーザーがデータを効率的に管理。

### 4. 相場分析
- **概要**: 相場検索データを基に売れ筋商品を分析。
- **機能**:
  - **ワードクラウド**: 売れている商品に含まれるフレーズを可視化。
  - **棒グラフ**: 価格帯と個数を表示し、価格幅を把握。
- **用途**: 市場トレンドを視覚的に理解。

### 5. 市場分析（実装予定）
- **概要**: 現在出品中の商品から注目商品をピックアップ。
- **予定機能**:
  - 相場価格と比較し、お買い得商品や目玉商品を特定。
- **目標**: 競争激しい市場での優位性を確保。

### 6. 未定
- **ステータス**: 機能未定。
- **計画**: 今後のフィードバックを基に追加予定。
