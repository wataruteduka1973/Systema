情報分析ツール システマ

このツールは、Yahoo!オークションの購入や出品に関する価格と傾向を分析し、意思決定を支援します。終了商品、現在出品中の商品、ローカルに保存した検索結果を用途別の画面で扱います。

✨ 特徴

  • 終了商品検索: 終了価格、開始価格、入札数、終了時間を確認・並べ替え。

  • 現在出品検索: 現在価格、入札数、残り時間を確認。

  • データ可視化: グラフやワードクラウドでトレンドを視覚化。

  • 価格分析: 保存済みデータから価格推移や予測値を算出。

🚀 インストール

  1. リポジトリをクローンします。

    git clone https://github.com/wataruteduka1973/Systema.git
cd Systema

  2. Windowsでは run_systema.bat を実行します。.venv の作成、依存関係の導入、マイグレーション、開発サーバー起動が行われます。

  3. ブラウザで http://127.0.0.1:8000/taskle/ を開きます。

手動セットアップや開発コマンドは開発ガイドを参照してください。
