API

Main.views.api.RealtimeSearch(request)[ソース]

現在出品されている商品のデータを取得して処理する。

Main.views.api.alert_rule_item(request, alert_rule_id)[ソース]

Read, update, or delete an owner-scoped alert rule.

Main.views.api.alert_rules(request)[ソース]

List or create rules owned by the authenticated user.

Main.views.api.complex_market_data(request)[ソース]

指定キーワードの落札履歴と現在出品中データを取得し、分析結果を返す

Main.views.api.convert_watch_item_to_inventory(request, watch_item_id)[ソース]

本人の購入候補を重複なく仕入済み在庫へ変換する。

Main.views.api.delete_market_data(request)[ソース]

フロントエンドから取得した対象を削除する

Main.views.api.get_market_data(request)[ソース]

データベースにアクセスして過去の検索履歴を取得する。

Main.views.api.get_popular_words(request)[ソース]

使用頻度の高い検索ワードを返す

Main.views.api.get_search_words(request)[ソース]

データベースにアクセスして過去の検索履歴を取得する

Main.views.api.handle_search_response(request, data_fetch_func, save_func=None, include_condition_analysis=False, search_type='closed', criteria=None)[ソース]

共通の検索処理を行うヘルパー関数。

Main.views.api.inventory_item(request, item_id)[ソース]

本人の在庫だけを参照、更新、削除する。

Main.views.api.inventory_items(request)[ソース]

本人の在庫を一覧、または手動登録する。

Main.views.api.inventory_profit_simulation(request, item_id)[ソース]

本人の在庫について、入力値を保存せず見込み利益を計算する。

Main.views.api.notification_item(request, notification_id)[ソース]

本人の通知だけを既読または未読へ更新する。

Main.views.api.notifications(request)[ソース]

本人の通知一覧と未読件数を返す。

Main.views.api.notifications_read_all(request)[ソース]

本人の未読通知を一括で既読にする。

Main.views.api.perform_search(request)[ソース]

相場のデータを取得して処理する。

Main.views.api.prediction_market(request)[ソース]

過去90日間の価格推移を分析し、異常値を排除した90日移動平均と1ヶ月予測を返す。
