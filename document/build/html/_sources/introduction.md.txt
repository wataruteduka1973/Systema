# 情報分析ツール システマ

このツールは、Yahoo!オークションの**購入**や**出品**に関する価格と傾向を分析し、意思決定を支援します。終了商品、現在出品中の商品、ローカルに保存した検索結果を用途別の画面で扱います。

## ✨ 特徴
- **終了商品検索**: 終了価格、開始価格、入札数、終了時間を確認・並べ替え。
- **現在出品検索**: 現在価格、入札数、残り時間を確認。
- **データ可視化**: グラフやワードクラウドでトレンドを視覚化。
- **価格分析**: 保存済みデータから価格推移や予測値を算出。

## 📋 主な機能

| 機能名       | 概要                                      | 特徴                                   | 用途                          |
|--------------|-------------------------------------------|----------------------------------------|--------------------------------|
| **相場検索** | 終了商品のデータを取得                     | 終了金額・入札数確認、フィルタリング    | 購入・出品戦略の策定           |
| **現在価格検索** | 現在出品中の商品データを取得         | リアルタイム金額・入札数確認            | 市場価格の把握                 |
| **過去情報参照** | 保存済みの取得データを確認            | データ更新・削除                       | データ管理                     |
| **相場分析** | 売れ筋商品を分析                         | ワードクラウド、棒グラフ               | 市場トレンドの理解             |
| **ターゲット分析** | 注目商品をピックアップ              | 相場との比較、お買い得商品特定         | 購入候補の選定                 |
| **相場予想** | 今後の商品価格を予想                      | 保存データによる価格推移と予測         | 落札価格の推測・出品分析       |



## 🚀 インストール

1. リポジトリをクローンします。

   ```bash
   git clone https://github.com/wataruteduka1973/Systema.git
   cd Systema
   ```

2. Windowsでは `run_systema.bat` を実行します。`.venv` の作成、依存関係の導入、マイグレーション、開発サーバー起動が行われます。

3. ブラウザで <http://127.0.0.1:8000/taskle/> を開きます。

手動セットアップや開発コマンドは[開発ガイド](development.md)を参照してください。
