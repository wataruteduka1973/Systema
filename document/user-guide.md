# 画面・機能ガイド

## アカウントと管理者セットアップ

一般ユーザーは「アカウント作成」から登録できます。登録後はウォッチリストがユーザーごとに分離され、同じ商品を複数のユーザーがそれぞれ登録できます。ヘッダーのユーザー名からユーザーページへ移動し、パスワード変更やログアウトができます。

ログイン中のユーザー名を押すとユーザーページを表示します。検索回数、取得商品数、ウォッチ商品数、よく使う検索ワード、最近の検索実行を確認でき、検索履歴を選択するとその検索で保存された商品を表示します。パスワード変更もこのページから行えます。管理者だけに開発者画面とDjango管理画面へのリンクが表示されます。

初回だけ `/accounts/admin-setup/` から管理者を作成できます。この画面はスーパーユーザーが1人作成されると自動的に無効になります。管理者は `/taskle/developer/` でデータ件数とログを確認し、詳細なユーザー・データ管理は `/admin/` を使用します。

## 相場検索

検索欄へキーワードを入力して実行すると、終了商品の商品名、終了価格、開始価格、終了時間、入札数、商品URLが表示されます。価格範囲と入札数で絞り込みでき、各列のボタンで昇順・降順に並べ替えられます。

商品名の記載から「新品・未使用」「中古・動作品」「ジャンク・故障品」「未分類」を判定し、状態別の件数と価格中央値を表示します。状態による絞り込みやジャンク品の除外も可能です。「動作確認済み」「本体のみ」「付属品あり」「箱あり」「まとめ売り」「送料無料」は補助属性として商品状態欄へ表示されます。

分類は商品名に含まれる語句を根拠とするため、出品者の記載が不十分な商品は「未分類」になります。ジャンクを除く中央値は、ジャンク以外の新品・中古・未分類商品を対象に算出します。

終了時間は、現在価格検索の残り時間と同じ「日・時間・分」単位で表示されます。終了済みの値には「前」が付きます。

## 現在価格検索

現在出品中の商品でも、商品名からコンディションと補助属性を判定し、状態別の件数・現在価格中央値を表示します。商品状態による絞り込みとジャンク品の除外に対応し、絞り込み後は価格帯と状態別集計も再計算されます。

出品中の商品名、現在価格、入札数、残り時間、商品URLを表示します。Yahoo!オークション側のページ構成や通信状態によって、取得件数や取得可否が変わることがあります。

## 検索結果の比較と価格変動

相場検索と現在価格検索では、表の「比較」チェックボックスから2～4商品を選択し、画面下部の「選択した商品を比較」を押すと比較画面を表示できます。価格、相場平均との差、商品状態、入札数、終了時間または残り時間を横並びで確認できます。

検索結果の上部にはデータ件数、中央値、価格変動幅、四分位範囲、変動係数、外れ値候補数を表示します。比較画面では選択商品の価格バーと、市場全体の価格分布ヒストグラムを表示します。外れ値候補はIQR方式で判定しますが、異常な商品であることを断定するものではありません。

## ウォッチリストと買い時判定

ターゲット分析の検索結果から「ウォッチリストへ追加」を押すと、商品を利用者専用のウォッチリストへ保存できます。ログイン中はユーザー単位、未ログイン時はブラウザーの匿名セッション単位で管理します。Yahoo!オークション側のウォッチリストとは連携しません。

匿名状態で登録したウォッチ商品と検索履歴は、同じブラウザーでログインまたはアカウント作成すると、そのユーザーへ自動的に引き継がれます。Cookieを削除した場合や別のブラウザーからアクセスした場合、引き継ぎ前の匿名データは参照できません。

ウォッチリストでは、現在価格、追加時価格、価格変化、買い時判定、最終確認日時を表示します。同じ商品をターゲット分析で再取得すると、現在価格、入札数、残り時間と買い時判定が更新されます。「ウォッチ解除」でSystemaのウォッチリストから削除できます。

買い時判定は、現在価格を落札価格の中央値と比較して「かなり買い時」「買い時」「検討候補」「様子見」に分類します。終了まで1時間以内の商品はスコアへ加点します。ジャンク・故障品は価格にかかわらず「要注意」、有効な相場データがない場合は「判定材料不足」と表示します。この判定は購入結果を保証するものではありません。

## 保存データと分析

相場検索の結果は検索キーワードと検索実行情報とともにSQLiteへ保存されます。保存結果はログインユーザーまたは匿名セッションごとに分離され、他の利用者の履歴は表示・更新・削除できません。過去情報参照で自分の保存済みデータを管理し、相場分析・ターゲット分析・相場予想で再利用します。

相場分析では、保存済みデータの件数、中央値、平均価格、価格変動、外れ値候補を表示します。価格推移は日次中央値と中央50%の価格帯（IQR）で確認でき、商品状態別の件数と中央値も比較できます。

相場データを更新すると、最新の商品情報に加えて検索時点の中央値とIQRが履歴として最大50回分保存されます。価格推移グラフと取得履歴表では、更新ごとの変化を確認できます。価格分布グラフは極端な外れ値候補を表示範囲から除外しますが、件数や全体統計からは削除しません。

過去データ参照でも、商品状態別の件数・中央値、状態による絞り込み、ジャンク除外を利用できます。表の比較欄から2～4商品を選ぶと、保存済み商品の価格差、状態、入札数を比較できます。

相場予想では、直近90日のデータを日単位で集計し、IQRによる外れ値候補を除いた日次中央値から30日後の価格を推定します。日次中央値、14日移動中央値、予測値、予測範囲、分析に使用した件数を表示します。予測値は将来の価格を保証するものではありません。

## 注意事項

- 外部サイトへ短時間に大量のリクエストを送らないでください。
- 表示価格や予測値は参考情報です。購入・出品の最終判断は利用者が行ってください。
- 外部サイトのHTML変更により取得処理が動かなくなった場合は、パーサーとfixtureテストを先に確認してください。
