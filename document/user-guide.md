# 画面・機能ガイド

## 画面一覧

| 画面 | URL | 主な用途 |
|---|---|---|
| ホーム | `/taskle/` | 各機能への入口 |
| 相場検索 | `/taskle/yahuoku` | 終了商品の検索、価格・入札数・終了時間の比較 |
| 現在価格検索 | `/taskle/yahuoku_now` | 出品中商品の現在価格・残り時間の比較 |
| 過去情報参照 | `/taskle/yahuoku_history` | 保存済み検索結果の表示、更新、削除 |
| 相場分析 | `/taskle/Deep_Analysis` | 終了商品の価格傾向や商品名の分析 |
| ターゲット分析 | `/taskle/Deep_Analysis_now` | 終了相場と現在出品商品を比較 |
| 相場予想 | `/taskle/Yahuoku_prediction` | 保存済みデータから価格推移・予測を表示 |
| このツールについて | `/taskle/introduction` | アプリケーションの概要 |

## 相場検索

検索欄へキーワードを入力して実行すると、終了商品の商品名、終了価格、開始価格、終了時間、入札数、商品URLが表示されます。価格範囲と入札数で絞り込みでき、各列のボタンで昇順・降順に並べ替えられます。

終了時間は、現在価格検索の残り時間と同じ「日・時間・分」単位で表示されます。終了済みの値には「前」が付きます。

## 現在価格検索

出品中の商品名、現在価格、入札数、残り時間、商品URLを表示します。Yahoo!オークション側のページ構成や通信状態によって、取得件数や取得可否が変わることがあります。

## 保存データと分析

相場検索の結果は検索キーワードとともにSQLiteへ保存されます。過去情報参照で保存済みデータを管理し、相場分析・ターゲット分析・相場予想で再利用します。

## 注意事項

- 外部サイトへ短時間に大量のリクエストを送らないでください。
- 表示価格や予測値は参考情報です。購入・出品の最終判断は利用者が行ってください。
- 外部サイトのHTML変更により取得処理が動かなくなった場合は、パーサーとfixtureテストを先に確認してください。
