# 情報分析ツール システマ

このツールは、Yahoo!オークションでの**仕入れ**と**出品**を、相場データにもとづいて判断できるようにするDjango製ウェブアプリケーションです。落札相場と現在の出品を調べるところから、狙い目商品の発見、仕入れ予算の試算、出品の管理、販売実績の集計、定期的な取得とアラート通知までを1つのアプリで扱います。

## 主な機能

| 機能 | 概要 | 主な用途 |
|---|---|---|
| **市場検索** | 落札相場・現在出品・保存済みデータを1画面で検索し、相場の要約と相場比を表示 | 相場の把握、割安な出品の発見 |
| **相場分析** | 保存データの概要と、落札データからの30日後の相場予想・バックテスト | 価格の見通し |
| **ターゲット分析** | 落札相場と現在の出品を比べて買い時の商品をカード表示、ウォッチリスト | 仕入れ候補の選定 |
| **出品・在庫管理** | 在庫と自分の出品を登録し、見込み利益と次の対応を表示、販売結果を確定 | 出品の管理 |
| **販売実績分析** | 確定した販売結果を期間・月別・費用内訳で集計 | 利益の振り返り |
| **アラート・通知** | 保存検索の定期取得（頻度を選択）と条件に一致した商品の通知 | 見逃し防止 |

画面ごとの使い方は[画面・機能ガイド](user-guide.md)を参照してください。

## インストール

1. リポジトリをクローンします。

   ```bash
   git clone https://github.com/wataruteduka1973/Systema.git
   cd Systema
   ```

2. Windowsでは `run_systema.bat` を実行します。`.venv` の作成、依存関係の導入、PostgreSQLへの接続確認、マイグレーション、開発サーバーとアラートのスケジューラーの起動が行われます。

3. ブラウザで <http://127.0.0.1:8000/taskle/> を開きます。

データベースの設定や手動セットアップは[開発ガイド](development.md)を参照してください。
